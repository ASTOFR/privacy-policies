Studio Analytics — Privacy

Privacy Policy

Effective 21 August 2026

Studio Analytics is a private, single-operator tool that reads publicly-available TikTok account statistics (follower count, likes, video count and public video metadata) through TikTok's official Login Kit, for two TikTok accounts the operator owns: @UncoveredEmpires and @SiliconHours.

It is not a public product. It is not distributed, and no third party can connect an account to it.

What is accessed

  • user.info.basic / user.info.stats — display name, avatar, follower count, following count, likes count, video count.
  • video.list — public video metadata: title, cover, view count, like count, comment count, share count.

Where it goes

Everything read from the TikTok API is written to a SQLite database file on the operator's own computer. Nothing is uploaded to a server, sold, shared with advertisers, or used to train any model. The only place this data is displayed is a local dashboard served on 127.0.0.1 — not reachable from outside that machine.

Retention

Historical snapshots are kept indefinitely on the local machine so the operator can chart growth over time. Older operational logs are purged automatically after 90–180 days; the analytics history itself is not.

Revoking access

Either account can revoke this app's access at any time from TikTok's own settings — Settings → Security → Manage apps — which immediately stops all data access with no action needed here.
